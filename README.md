# Ultimate Block Breaker

![Curseforge](https://img.shields.io/curseforge/dt/931756?logo=curseforge&label=&suffix=%20&style=for-the-badge&color=242629&labelColor=e04e14&logoColor=1c1c1c)
![Version](https://img.shields.io/curseforge/v/931756?style=for-the-badge)
![Game Versions](https://img.shields.io/curseforge/game-versions/931756?style=for-the-badge)

This add-on adds different tiered block breakers to break any blocks (besides bedrock). Perfect for automating cobblestone generators.

## Contributing

This repository has multiple branches for each platform this Minecraft mod supports.
